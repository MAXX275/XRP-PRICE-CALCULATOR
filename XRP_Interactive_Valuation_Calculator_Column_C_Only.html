Model and assumptions

Steady-state XRP price: P = ρ × (Y × t + I) / (N + γ), with transaction and storage demand expressed in compatible units.

Present value: P / (1 + i)T. Probability-weighted value: success probability × present value + (1 − success probability) × failure-case value.

This page reproduces only column C (XRP Price Calc) of the supplied workbook; column B is excluded. XRP burn is calculated using its fixed workbook assumption of 0.00001 XRP per transaction. The annual transaction capacity calculation is a model-derived quantity, not a prediction of actual ledger transactions. Values are illustrative scenarios, not investment advice.

Source: Robert Mitchnick and Susan Athey, A Fundamental Valuation Framework for Cryptoassets (June 2018). Input defaults and calculations transcribed from the uploaded spreadsheet.

Standalone calculator: all calculations run locally in your browser; no network connection is required.
